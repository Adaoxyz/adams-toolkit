# Nome e marca

O código deste repositório está sob a [GPL-3.0](LICENSE). O **nome** e a **imagem**
da aplicação não estão.

Não abrangido pela licença:

- o nome **"Adams Toolkit"** e variações que se confundam com ele;
- os ficheiros em `Assets/` — `logo.png`, `app.ico`;
- o nome e a identidade visual da comunidade **WestRP**.

## O que isto significa na prática

**Podes**, sem pedir nada a ninguém:

- ler, estudar e auditar o código;
- compilar para uso próprio;
- fazer um fork, alterar o que quiseres e distribuí-lo — sob a GPL-3.0, com o
  código aberto — **desde que lhe dês nome e logo próprios**;
- dizer honestamente que o teu projeto "é baseado no Adams Toolkit".

**Não podes**:

- distribuir uma versão alterada com o nome "Adams Toolkit" ou com o logo original;
- apresentar um fork como se fosse a aplicação oficial, ou como se tivesse o apoio
  da comunidade WestRP.

O motivo é simples: se aparecerem cópias modificadas com o nosso nome, quem se
magoa são os jogadores que instalam uma delas a pensar que é a original — e a
confiança na aplicação é exatamente o problema que este repositório existe para
resolver.

Para usar o nome ou o logo, pergunta primeiro.
